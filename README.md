## Overview

String Studio VS-3 models plucked, bowed, and struck string instruments through physical simulation of string tension, damping, and resonant body behavior for realistic stringed instrument tones.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **AAS String Studio** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Physical String** | Simulation models string tension, material stiffness, and inharmonicity |
| **Exciter Types** | Pluck, bow, hammer, and mallet exciters for diverse articulations |
| **Body Model** | Adjustable acoustic body resonance from guitar to sitar character |
| **MIDI Articulation** | Velocity and aftertouch control bowing pressure and pluck attack |
